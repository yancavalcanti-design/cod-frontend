# 💻 Frontend Coding Challenges & Exercises

- **Linguagens:** HTML5, CSS3, JavaScript (ES6+), TypeScript
- **Frameworks & Libs:** React, Next.js, Vue.js *(adapte conforme o uso)*
- **Estilização:** Tailwind CSS, Styled Components, Sass
- **Ferramentas:** Git, VS Code, Vite, Live Server
